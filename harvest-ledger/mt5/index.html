🔗 ดึงเทรดจาก MT5 อัตโนมัติ

ทำงานยังไง

MT5 บนคอม (EA) ➜ GitHub Gist ลับ ➜ Harvest Ledger บนคอม + iPhone

EA ตัวเล็กใน MT5 คอยส่งเทรดที่ปิดแล้วขึ้น Gist ทุกครั้งที่มีดีลใหม่ แอปบนทุกเครื่องดึงจาก Gist เองทุก 2 นาที และทุกครั้งที่เปิดแอป เทรดที่เปิดจาก แอป MT5 บนมือถือ ก็ถูกส่งด้วย เพราะเป็นบัญชีเดียวกัน ขอแค่ MT5 บนคอม (หรือ VPS) เปิดอยู่

ขั้นที่ 1 · สร้าง Gist ลับ (ครั้งเดียว)

  1. เข้า gist.github.com แล้วล็อกอิน
  2. ชื่อไฟล์: harvest-ledger.json · เนื้อหา: []
  3. กด Create secret gist
  4. คัดลอก Gist ID คือรหัสยาวท้ายลิงก์ เช่น gist.github.com/ชื่อคุณ/3f2a9c…

ขั้นที่ 2 · สร้าง Token ให้ EA เขียน Gist ได้

  1. เข้า GitHub → New token (classic) (ลิงก์นี้ติ๊ก scope gist ไว้ให้แล้ว)
  2. ตั้ง Expiration ตามต้องการ แล้วกด Generate token
  3. คัดลอก token (ขึ้นต้นด้วย ghp_) เก็บไว้ ใช้ใน MT5 บนคอมเท่านั้น ไม่ต้องใส่ในมือถือ

ขั้นที่ 3 · ติดตั้ง EA ใน MT5 บนคอม

⬇ ดาวน์โหลด HarvestLedgerSync.mq5

เวอร์ชัน 1.10: ส่งระยะเวลาที่ถือแต่ละไม้ด้วย (ใช้ใน heatmap เวลาเปิดออร์เดอร์, การจับเทรดแก้แค้น และสถิติเวลาถือไม้ชนะ/แพ้) ถ้าติดตั้งเวอร์ชันเก่าไว้ ให้ดาวน์โหลดไฟล์ใหม่ไปทับ แล้วกด Compile อีกครั้ง

  1. ใน MT5 กด File → Open Data Folder แล้วนำไฟล์ไปวางใน MQL5\Experts
  2. กด F4 เปิด MetaEditor, ดับเบิลคลิกไฟล์ แล้วกด F7 (Compile)
  3. Tools → Options → Expert Advisors: ติ๊ก Allow WebRequest for listed URL แล้วเพิ่ม https://api.github.com
  4. ลาก HarvestLedgerSync จาก Navigator ไปวางบนกราฟไหนก็ได้ 1 กราฟ
  5. แท็บ Inputs: ใส่ InpGistId = Gist ID และ InpToken = token แล้วกด OK
  6. เปิดปุ่ม Algo Trading ให้เป็นสีเขียว (EA นี้ ไม่เปิดหรือปิดออร์เดอร์ แค่อ่านประวัติแล้วส่งออก)
  7. ดูแท็บ Experts ด้านล่าง ถ้าขึ้น Harvest Ledger: synced closed trades to the gist. แปลว่าใช้ได้

ขั้นที่ 4 · เชื่อมแอป (ทำในทุกเครื่องที่ใช้)

  1. เปิด Harvest Ledger แล้วกด ⚙ (หรือเดินไปที่ 📮 ตู้จดหมาย)
  2. ช่อง ดึงเทรดจาก MT5 อัตโนมัติ: วาง Gist ID (หรือวางทั้งลิงก์ก็ได้)
  3. กด 🔄 ซิงก์ตอนนี้ เทรดจะงอกเป็นผักในแปลง พร้อมแท็ก MT5 · รอจดบันทึก
  4. แตะเทรดนั้นแล้วกด แก้ไข เพื่อเติมอารมณ์ หัวใจ และบทเรียน (ได้ XP ตามปกติ)

ควรรู้

  • Gist ลับ ≠ ส่วนตัว 100% ใครมีลิงก์ Gist ก็อ่านประวัติเทรดได้ (ไม่มีรหัสผ่านหรือเลขบัญชีเทรดนอกจากเลข login) อย่าแชร์ลิงก์
  • Token เก็บไว้ในคอมเท่านั้น ใช้ได้แค่เขียน Gist ถ้าหลุด ลบทิ้งได้ที่ GitHub → Settings → Tokens
  • MT5 ต้องเปิดอยู่ ถ้าคอมปิด เทรดจะถูกส่งเมื่อเปิด MT5 ครั้งถัดไป (EA ส่งย้อนหลัง 90 วันเสมอ)
  • แก้ข้อมูลในแอปได้ อารมณ์ บทเรียน ฯลฯ ที่คุณจดจะไม่ถูกทับ ถ้าลบเทรด MT5 ในแอป จะไม่ถูกดึงกลับมาอีก
  • ไม่อยากใช้ Gist? ไม่ต้องใส่ token ก็ได้ EA จะเขียนไฟล์ MQL5\Files\harvest-ledger.json แล้วนำเข้าด้วยปุ่ม 📂 นำเข้าไฟล์จาก MT5 ในตั้งค่า
  • แอป MT5 บน iPhone/Android รัน EA ไม่ได้ (ข้อจำกัดของ MetaQuotes) จึงต้องมี MT5 บนคอมหรือ VPS 1 เครื่อง
