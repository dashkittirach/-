◀ กลับไปฟาร์ม

👥 เปิดโหมดเล่นกับเพื่อน

ทำงานยังไง

ล็อกอิน Google ➜ Firebase (ฟรี) ➜ เพื่อน · อันดับ · เยี่ยมฟาร์ม

ทำครั้งเดียวโดยเจ้าของเซิร์ฟเวอร์ (คุณ) ประมาณ 5–10 นาที เพื่อนไม่ต้องตั้งค่าอะไร แค่กดลิงก์ชวนแล้วล็อกอิน

ความเป็นส่วนตัว: สมุดเทรดยังอยู่ในเครื่องของแต่ละคน บนเซิร์ฟเวอร์มีแค่ข้อมูลเกม (ชื่อฟาร์ม เลเวล จำนวนวันที่ทำตามกฎ ฟาร์ม และผลผลิตแบบ ชนะ/แพ้) ไม่มีจำนวนเงิน สินทรัพย์ หรือบันทึก

ขั้นที่ 1 · สร้างโปรเจกต์

  1. เข้า console.firebase.google.com ล็อกอินด้วย Google
  2. กด Create a project (สร้างโปรเจกต์) ตั้งชื่อ เช่น harvest-ledger
  3. หน้า Google Analytics ปิดได้ แล้วกด Create project

ขั้นที่ 2 · เปิดล็อกอินด้วย Google

  1. เมนูซ้าย Build → Authentication → Get started
  2. แท็บ Sign-in method → เลือก Google → เปิด Enable → เลือกอีเมลของคุณในช่อง support email → Save
  3. แท็บ Settings → Authorized domains → Add domain → ใส่ dashkittirach.github.io

ขั้นที่ 3 · สร้างฐานข้อมูล + ใส่กฎความปลอดภัย

  1. เมนูซ้าย Build → Firestore Database → Create database
  2. Location เลือก asia-southeast1 (Singapore) → เลือก Start in production mode → Create
  3. แท็บ Rules → ลบของเดิมทั้งหมด → วางกฎด้านล่าง → Publish

กำลังโหลด…

กฎนี้ทำให้: แต่ละคนแก้ได้เฉพาะฟาร์มตัวเอง · เขียนสมุดเยี่ยมได้ในชื่อตัวเองเท่านั้น (ไม่เกิน 140 ตัวอักษร) · คนที่ไม่ได้ล็อกอินอ่านอะไรไม่ได้เลย

ขั้นที่ 4 · เอาค่า config มาใส่ในแอป

  1. กด ⚙️ Project settings (มุมซ้ายบน) → เลื่อนลงไปที่ Your apps → กดไอคอน </> (Web)
  2. ตั้งชื่อแอป เช่น harvest-web → Register app (ไม่ต้องติ๊ก Hosting)
  3. คัดลอกก้อน const firebaseConfig = { … } ทั้งก้อน
  4. เปิด Harvest Ledger → ปุ่ม 👥 มุมขวาบน → วางลงช่อง → บันทึกและเชื่อมต่อ

ค่า config นี้เปิดเผยได้ ไม่ใช่รหัสผ่าน ความปลอดภัยมาจากกฎในขั้นที่ 3 · ถ้าส่งค่านี้ให้ผู้พัฒนาใส่ไว้ในโค้ด เพื่อนจะเข้าได้ทันทีแม้ไม่ได้ใช้ลิงก์ชวน

ขั้นที่ 5 · ชวนเพื่อน

  1. 👥 → แท็บ เพื่อน → 📨 ชวนเพื่อน ส่งลิงก์ทาง LINE/Messenger
  2. เพื่อนเปิดลิงก์ → ล็อกอินด้วย Google → เป็นเพื่อนกันอัตโนมัติ
  3. หรือบอกโค้ด 6 ตัวของคุณ ให้เพื่อนกด ＋ เพิ่ม ก็ได้

แพ็กเกจฟรี (Spark) ของ Firebase อ่านได้วันละ 50,000 ครั้ง เขียนได้ 20,000 ครั้ง กลุ่มเพื่อนหลักสิบคนใช้ไม่ถึง 1%
